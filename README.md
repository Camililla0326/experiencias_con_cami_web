# Sitio web — Experiencias con Cami

Proyecto académico construido con HTML5, CSS3, JavaScript y Materialize CSS 1.0.0.

## Publicar gratis en GitHub Pages
1. Inicia sesión en https://github.com y crea un repositorio público llamado `experiencias-con-cami-web`.
2. Sube `index.html`, `style.css` y `script.js` a la raíz del repositorio.
3. Entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/ (root)`. Pulsa **Save**.
6. Espera la publicación y abre la URL que GitHub Pages muestra. Tendrá esta forma: `https://TU-USUARIO.github.io/experiencias-con-cami-web/`.
7. Verifica el enlace en una ventana privada y entrega esa dirección al instructor.

## Importante
El formulario es una demostración estática: prepara un correo mediante `mailto:` y el visitante debe confirmar el envío desde su aplicación de correo. No existe base de datos ni servidor. La página requiere Internet para cargar Materialize, fuentes e imágenes enlazadas externamente.
